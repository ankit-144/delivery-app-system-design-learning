QuickDrop: how it fits together

A tiny quick-commerce backend grown phase by phase, from one instance and one database to three instances, Redis, a sharded database, Kafka and full observability. Everything runs locally in Docker Compose.

Phases

  • P0
    Baseline

    One instance, one database, eyes on: latency percentiles, Flyway.

  • P1
    Correctness under concurrency

    Oversold stock, double-booked riders, duplicate orders, deadlocks.

  • P2
    One box hits the wall

    Slow vendor, pool exhaustion, missing index, N+1, no timeouts, virtual threads.

  • P3
    Scale out

    Three instances and Redis: in-memory state, locks, rate limits, stampedes, load balancing.

  • R
    Redis deep dive

    KEYS, big keys, eviction, persistence, round trips, pub/sub vs streams.

  • P4
    Live schema changes

    Locks during ALTER, backfills, expand / contract, Flyway in production.

  • P5
    Scaling the database

    Replica lag, read-your-writes, sharding, resharding, cross-shard moves.

  • P6
    Notifications

    Sync chain → queues → Kafka: outbox, vendor rate limits, priority topics.

  • P7
    Kafka deep dive

    Partitions, ordering, delivery semantics, poison pills, rebalances, acks, compaction, transactions.

  • P8
    Operating it

    Tracing, SLO burn-rate alerts, retry storms, load shedding, game day.

Repository map

  • services/core-service

    Orders, stock, riders. Every BROKEN and FIX strategy, plus the database, Redis and sharding labs.

  • services/notification-service

    SMS delivery modes, Kafka consumers, the Kafka lab (K1–K11), the alert webhook.

  • services/vendor-mock

    The fake SMS vendor: latency, errors, 429s, queueing.

  • libs/quickdrop-common

    Runtime toggles, strategy selection, chaos knobs, retries, tracing filters.

  • infra/

    docker-compose.yml and every config: Prometheus rules, Alertmanager, Grafana, Tempo, Loki, nginx, Toxiproxy.

  • loadtest/k6/

    One load script per scenario and the shared helpers.

  • scenarios/

    69 runbooks: story, how to run it, measured results, why, discussion.

  • scripts/

    Toggles, toxics, the Kafka acks lab (K6), game day.

  • docs/

    Cheat sheet, failure tracker, build log, this page.
